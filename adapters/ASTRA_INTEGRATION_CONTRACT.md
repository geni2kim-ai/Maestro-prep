# Generic external planning integration

The coordinator supports an existing separately approved planning installation and an optional immutable public reference for **test-only** compatibility. A public reference is not a host-approved installation. The owner supplies an independent lock/pin for the actual local validator, schema, profile, skill contract and complete installed bundle manifest.

New-plan and replan requests require approved planning output; reusing a previous plan requires original route/plan byte bindings and monotonic chronology. Missing pins or mismatched bytes HOLD; never re-sign upstream manifests to declare success. Installation names and absolute local paths are configured outside the public repository. The O-Prep gate remains mandatory whenever a bound check is required.
