# 배포 전 로컬 확인 절차 — 공개용

이 문서는 실제 운영 호스트 경로나 특정 팀의 내부 스킬 이름을 제공하지 않습니다. 노드 소유자가 별도로 제공한 버전·파일 해시와 실제 바이트를 읽기 전용으로 비교하고, 불일치하면 HOLD하십시오. 승인된 라우팅·계획·증거 컴포넌트는 자동으로 설치하거나 교체하지 마십시오. 실제 실행, 독립 검토, 롤백 시뮬레이션 및 소유자 승인은 이 후보의 외부 필수 게이트입니다.

전달 도구는 `tools/local_node_preflight.py`와 `tools/audit_external_archive.py`입니다. 원본 호스트 경로·정책·비공개 영수증은 공개 리포지토리에 올리지 마십시오.
