# Maestro-Prep 공개 후보

외부 라우팅 결과, 독립적으로 승인된 계획, 필수 증거 게이트를 함께 확인하는 **읽기 전용·후보 전용** 진입점입니다. 공개 저장소에는 실제 운영 노드의 이름·경로·정책·로그·내부 워크플로 이력·비공개 저장소 주소 및 특정 증거 ZIP의 구성 정보를 포함하지 않습니다.

- `python tools/ci_check.py`: 합성 사례와 변경 코드 회귀 시험.
- `python -m maestro_prep.cli component-check`: **공개용으로 비식별화한** O-Prep 호환 소스의 해시 확인. 기존 원본 O-Prep의 승인 핀이 아니므로 실제 설치본은 외부 소유자 핀으로 별도 확인해야 합니다.
- `python tools/audit_external_archive.py --help`: 특정 노드 구조를 사용하지 않는 일반 ZIP 바이트 감사. 실제 라우팅 의미 검사에는 로컬 비공개 승인 프로필이 필요합니다.
- `python tools/local_node_preflight.py --help`: 현재 설치본과 외부 승인된 바이트 고정값의 읽기 전용 사전 점검.

로컬 승인본의 이름과 경로는 공개 소스에 상수로 저장하지 마세요. 승인권자가 제공한 별도 설정에서만 주입하세요. 상세한 내부 라우팅 계약·역사적 정정 기록·증거 구성은 공개 패키지 대신 승인된 로컬 채널에서만 보유해야 합니다. 이 패키지나 CI 통과로 설치·배포·권한·독립 리뷰를 주장하지 않습니다.
