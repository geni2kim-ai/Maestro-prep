# 20개 합성 구조 비교와 실제 노드 적용 사이의 경계

이전 비교는 O-Prep v0.3 결정 엔진을 직접 평가했지만 Astra-Prep/Leonardo 분기는 **모형**으로 처리했다. 이번 패키지의 `tools/replay_simulation.py`도 과거 20개 분기를 독립적으로 재구성한 입력을 O-Prep의 고정 원본에 재투입하여 예상 결과를 확인한다. 입력 원문이 아니라 재구성된 fixture이므로 실제 타 노드의 성능, 무결성, 보안 위험 발생 확률을 추정할 수 없다.

기존 A0/B의 부적절한 단일 라우팅은 20개 중 검증이 필요한 합성 상황 11개에서 O-Prep 검사 없이 계획만 진행할 수 있었다. C안 모델은 O-Prep이 설치된 합성 시나리오에서 해당 강제 게이트를 생략하지 않았다(0건). 실측 처리량, LLM 정확도, 운영 승인은 모두 `NOT_RUN`이다. 이전 요약의 20개 시나리오 ID와 재연 결과만 포함했으며 원본 로컬 로그나 코드베이스를 포함하지 않는다.

공식 Astra 버전/핀, Leonardo 정책/라우터의 정확한 정본, 로컬 노드의 host-generated raw receipt 및 승인권자 서명을 받은 뒤에만 실제 통합 시험으로 승격할 수 있다.
